# AI 外贸全链路系统 · 产品蓝图 v0.1

> 整理自 2026-07-04 白板 + 口述。定位：先给自己公司用，跑通后打包成系统对外销售。

## 一句话定义

围绕外贸业务「获客 → 转化 → 管理」三个环节，做一套以**自建 CRM 为数据中枢**、以**"AI 辅助人而不是替代人"**为原则的工具系统。

## 核心设计原则（不可动摇的三条）

1. **AI 是"放大器"，不是"替代者"**。目标不是裁员和无人化，而是给每个销售配一个虚拟销冠、给每个员工配一个虚拟专家，让普通人变强。
2. **人可以大量介入前端**（文案、素材、判断、最终拍板），AI 负责重复性、规模化、24 小时在线的部分。AI 给建议，人做决定。
3. **先自用，再卖**。自己公司是第一个客户和试验田；架构从第一天就按"以后要卖给别人"设计（多租户、知识库可配置）。

## 三大端总览

| 端 | 解决的问题 | 包含模块 |
|---|---|---|
| 流量端 | 进线 | ①视频号 AI 视频工厂 ②广告投放自动化 ③主动客户开发 |
| 销转端 | 复制销冠 | ④自建 CRM ⑤WhatsApp 接入与工作台 ⑥存量客户批量分析 ⑦初筛客服 AI ⑧销冠辅助+翻译+自动跟进纪要 |
| 企业管理端 | 内部提效 | ⑨技术分身 ⑩老板分身 ⑪人事/财务（远期） |

## 流量端

### 模块① 视频号 AI 视频工厂
**做什么**：固定模板 + 产品素材 → 批量生成不需要拍摄、不需要真人出镜的营销视频，稳定投喂视频号。

**拆解**：
1. 模板库：把"跑得动的视频结构"拆成可复用模板（开头钩子 / 卖点展示 / 场景 / 行动号召）
2. 素材库：产品图、视频片段、3D 渲染、字幕、AI 配音（数字人可选）
3. 生成流水线：选题 → AI 写脚本 → 套模板合成 → **人工审核** → 发布
4. （二期）数据回流：哪类模板/选题效果好，反哺选题策略

**技术要点**：程序化模板剪辑比纯 AI 生成视频更稳定可控、成本更低；视频号自动发布受平台限制，初期人工发布。

**需要老板提供**：
- [ ] 对标账号/爆款视频链接 5–10 个（用来拆模板）
- [ ] 现有素材盘点：产品图/视频/3D 在哪、什么格式
- [ ] 期望产量（每天/每周几条）、谁做终审
- [ ] 是否接受 AI 配音 / 数字人；语言（中文/英文/多语言）

### 模块② 广告投放自动化
**做什么**：文案脚本 → 视频生成 → 自动在广告账户建系列/建计划/投放 → 按效果数据优化 → 产出线索直接进 CRM。

**拆解**：
1. 创意端：AI 批量产文案+脚本+视频（复用模块①流水线，人可大量介入）
2. 投放端：对接广告平台**官方 Marketing API**，自动建 Campaign/AdSet/Ad
3. 优化端：定时拉数据，规则引擎 + AI 建议（关停差的、加预算好的、换素材）——初期"AI 建议、人确认"，跑顺后再逐步放开自动执行
4. 线索端：表单/落地页线索自动入 CRM，标注来源

**技术要点/风险**：模拟人工操作广告后台有封号风险，必须走官方 API（Facebook/Google/TikTok 都有）。

**需要老板提供**：
- [ ] 投放平台优先级（Facebook / Google / TikTok / 腾讯广告？）
- [ ] 广告账户现状：几个户、开户主体、历史投放数据
- [ ] 月预算量级、目标市场、目前单线索成本基准
- [ ] 现在谁在投、流程什么样

### 模块③ 主动客户开发
**做什么**：按目标客户画像从 Google/LinkedIn 等渠道批量找潜客 → AI 逐个背调判断是否目标人群 → 批量发邮件/WhatsApp → 自动优化话术 → 客户一回复即成线索进系统。

**拆解**：
1. 找客户：关键词策略 + 多渠道采集（Google、LinkedIn、行业目录、海关数据）
2. 判客户：打分规则（行业/职位/公司规模/进口记录/网站内容），AI 判定"是不是我们的人"
3. 触达：邮件序列（多轮自动跟进）+ WhatsApp 首触；A/B 测话术，按回复率迭代
4. 背调增强：公司数据、社媒账号、上下文 → 生成客户档案
5. 回复即线索：进"收到线索"看板 → 转销转端

**技术要点/风险**：批量邮件必须做域名信誉建设（独立发信域名、预热、退订合规），否则全进垃圾箱；WhatsApp 批量主动触达封号风险高，需要保守的账号与节奏策略。

**需要老板提供**：
- [ ] 目标客户精确定义：国家、行业、公司类型（进口商/经销商/工程商/终端）、决策人职位
- [ ] 最好的 20–50 个成交客户名单（反推画像和打分规则）
- [ ] 现有工具：领英账号、海关数据账号、邮箱群发工具
- [ ] 现有开发信/话术模板，谁写得最好

## 销转端（系统核心）

### 模块④ 自建 CRM（数据中枢）
所有数据的落点：广告线索、开发线索、聊天记录、标签、跟进纪要，前后端全打通。

**拆解**：客户档案 / 线索来源追踪 / 销售阶段流转 / 标签体系 / 跟进记录 / 权限体系 / 报表。

**需要老板提供**：
- [ ] 现在客户信息管理方式（Excel？现成 CRM？）→ 给现有表结构
- [ ] 销售流程阶段划分（询盘→报价→寄样→PI→…？）
- [ ] 现有标签划分体系（一页纸写清）
- [ ] 团队结构：几个销售、几个客服、汇报关系

### 模块⑤ WhatsApp 接入与网页工作台
**做什么**：在 CRM 网页里直接收发 WhatsApp，销售不用自己连外网、不用切软件。

**关键对齐点**："不连外网"的实际实现 = WhatsApp 连接放在境外服务器上中转，销售在国内浏览器访问我们自己的系统。两条路线需拍板：
- **路线 A：官方 WhatsApp Business API** —— 合规稳定不封号；但按对话收费、需用新企业号、不含旧号历史记录
- **路线 B：挂载现有个人/Business App 账号**（类似网页版）—— 能续用现有号和历史记录；但有封号风险
- 大概率混合：老客户维护走 B，规模化触达走 A

**需要老板提供**：
- [ ] 现有 WhatsApp 号数量、类型（个人/Business）、封号史
- [ ] 历史聊天记录是否必须保留

### 模块⑥ 存量客户批量分析
**做什么**：AI 通读全部 WhatsApp 历史对话（如 1000 个客户），逐个提取：客户是谁、买什么、聊到哪一步、卡在哪、多久没跟进 → 自动打标签 → 全量客户分析报告 → 导入 CRM。
**这是 CRM 冷启动最快的方式**——上线第一天客户档案就是满的。

**需要老板提供**：
- [ ] 几段真实完整客户聊天记录样本（可脱敏），用于设计提取字段和打标规则

### 模块⑦ 初筛客服 AI
**做什么**：新线索进来，AI 接住前 5–10 个问题：答基础问题（产品/价格区间/货期/MOQ）、反问收集画像（国家/用途/数量/预算/时间线）、完成基础背调，带着完整画像转人工。

**需要老板提供**：
- [ ] 客户最常问的 20 个问题 + 标准答案
- [ ] 红线清单：哪些问题 AI 绝对不能自己答（价格底线/账期等）
- [ ] "值得跟"客户的判定标准

### 模块⑧ 销冠辅助（系统灵魂）+ 翻译 + 自动跟进纪要
**做什么**：聊天框底部常驻"虚拟销冠"：通读该客户全部上下文 + 产品知识库 + 销冠销售思维 → 针对客户最新一条消息给建议回复。**可改、可不用，AI 递话、人拍板**。附带实时翻译；每次沟通后 AI 自动生成跟进纪要写回 CRM（销售不再手写纪要）。

**拆解**：产品知识库（结构化）→ 销冠话术库（从成交聊天记录里挖）→ 上下文引擎 → 建议生成 → 采纳率统计（哪些建议被采用，反哺优化）。

**需要老板提供**（全部资料里最值钱的部分）：
- [ ] 销冠的 10–20 段完整成交聊天记录（从询盘到下单全程）
- [ ] 销冠自己的经验总结：怎么报价、怎么逼单、怎么处理"太贵了/再考虑"
- [ ] 产品知识文档：规格、参数、价格体系、货期、认证、常见异议
- [ ] 主要沟通语言

## 企业管理端（后置）

### 模块⑨ 技术分身（管理端里建议最先做）
公司核心技术知识 → 内部问答机器人，业务员随时问，不再打断技术员。和模块⑧的产品知识库是同一份资产，做完销冠辅助顺手就有。
**需要**：技术资料位置（文档/图纸/老师傅脑子里）、技术员最常被问的 20 个问题。

处理老板日常琐碎事务的对话入口。需先列清单：哪些事务想交出去（审批提醒/日报汇总/信息查询…）。

## 依赖关系与建议节奏（两条线并行）

**内容线**（独立、见效快）：① 视频工厂 → ② 广告自动化

**数据中枢线**（系统的根）：④ CRM 骨架 + ⑤ WhatsApp 接入 → ⑥ 存量分析（冷启动）→ ⑧ 销冠辅助 → ⑦ 初筛客服 → ③ 主动开发（线索有地方接了再上）→ ⑨ 技术分身

逻辑：CRM 是一切的落点，先立起来；销冠辅助是最能体现"AI 帮人变强"、团队每天都摸得到的功能，最先建立信心；主动开发放在 CRM 之后，因为产出的线索要有地方进。

2. "龙虾的那种窗口" —— 指什么产品/形态？

## "以后要卖"对现在架构的影响

1. **多租户**：数据库第一天就按多公司隔离设计，避免日后重构
2. **可配置**：知识库、标签体系、话术模板全部做成每家公司可自配，不写死自家产品
3. 账号体系/计费**留口子**，不先做
4. 自己公司 = 第一个客户 + 试验田

## 老板现在就能做的三件事（不依赖技术）

1. 找销冠要 10–20 段完整成交聊天记录
2. 把标签体系和销售阶段写成一页纸
3. 收集客户最常问的 20 个问题 + 标准答案
