# 07 · 广告账户与投放资料

## 填写说明

- **喂给哪个模块**：广告投放模块——账户看板、系列/组/素材三层数据、AI 优化建议（哪个素材该停、哪个组该加预算）。没有真实账户数据，这个模块只能空转。
- **谁来填**：当前负责投放的操作人（或代理商对接人）主填；预算量级和平台优先级由老板定。
- **怎么收集**：登录各广告后台（Facebook Ads Manager / Google Ads），账户 ID 在后台右上角可查；历史数据在后台"报告"里按过去 90 天导出即可。没投过广告就只填"平台优先级 + 预算量级"两节，其余写"暂无"。
- **颗粒度**：账户信息填到账户 ID；历史数据只要三个数（花费/线索数/CPL），不需要导全表；预算写月度量级即可，不用精确到天。
